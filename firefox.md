## Preferences

- General
  - Check for default browser
  - Show home page about:newtab
  - Open new windows in new tab
  - **Do** load tabs before selected
  - Don't switch to new tab immediately
- Search
  - DuckDuckGo
  - Provide search suggestions
  - Show search suggestions in location bar results
  - Remove all other search engines
- Content
  - Block pop-up windows
* Privacy
  *   Use Tracking Protection in Private Windows
  *   Use custom settings for history (to allow search suggestions)
  *   **Don't** always use private browsing mode
      *   Don't remember my browsing and download history
      *   Don't remember search and form history
      *   Always accept cookies, but kill them when I close Firefox
      *   Clear history when Firefox closes
          *   Make sure to select everything
  *   Suggest History in the location bar (because it isn't stored anyway)
* Security
  *   Warn me when sites try to install add-ons
  *   Block reported attack sites
  *   Block reported web forgeries
  *   **Don't** remember logins for sites or use a master password
* Sync
  *   No Firefox account
