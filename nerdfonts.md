# Nerd Fonts

Go to the [Nerd Fonts downloads][] page, search for "Fira" to find the download
for the FiraCode Nerd Font, then click "Download". Unzip the folder, then [copy
all the files into `~/.local/share/fonts`][install fonts].

[install fonts]: https://askubuntu.com/a/3706/423065
[Nerd Fonts downloads]: https://www.nerdfonts.com/font-downloads
