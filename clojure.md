# Clojure

Use the [installation instructions from the website][install]. First download
the installation script:
```
$ wget -P /tmp https://download.clojure.org/install/linux-install-1.10.1.561.sh
```
Then give it the right permissions:
```
$ chmod +x /tmp/linux-install-1.10.1.561.sh
```
And run it:
```
$ sudo /tmp/linux-install-1.10.1.561.sh
```

[install]: https://www.clojure.org/guides/getting_started#_installation_on_linux
