# Miniconda

Follow the [instructions on the website][install], so first download the
installer:
```
$ wget -P /tmp https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
```
Then run it:
```
$ bash /tmp/Miniconda3-latest-Linux-x86_64.sh
```
Follow the instructions, answering "yes" to all prompts that ask for a yes/no
answer.

[install]: https://docs.conda.io/projects/conda/en/latest/user-guide/install/linux.html
