# Leiningen

Basically follow the [instructions from purelyfunctional.tv][install]. First
download into the right location:
```
$ wget https://raw.githubusercontent.com/technomancy/leiningen/stable/bin/lein
```
Then make it executable:
```
$ sudo chmod +x /usr/local/bin/lein
```

[install]: https://purelyfunctional.tv/guide/how-to-install-clojure/#mac-leiningen
