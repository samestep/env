# Gradle

To install Gradle, first [install SDKMAN!][sdkman]:
```
$ curl -s "https://get.sdkman.io" | bash
```
Then follow the [package manager instructions on the Gradle website][install]:
```
$ sdk install gradle 6.8
```

[install]: https://gradle.org/install/#with-a-package-manager
[sdkman]: https://sdkman.io/
